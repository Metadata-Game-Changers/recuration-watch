About: This tool measures Crossref metadata completeness — for a journal (ISSN), a publisher (Crossref member), or an organization’s ROR-identified works — with a reduced catalog of the Metadata Game Changers FAIR use cases: Text, Identifiers, and Connections, keeping only the 27 concepts the Crossref schema can express (FAIR Contacts, keywords, and geographic/temporal coverage have no Crossref counterpart — the About tab lists every concept, its Crossref source field, and the approximations). Each Crossref work is translated to the DataCite record shape and scored with the same jq queries as Metadata Completeness, so the methodology is identical; the totals are not comparable across registries. All scoring runs in your browser against live Crossref data — nothing is uploaded or stored.
Troubleshooting: if the scoring engine can't load from a CDN, download jq.asm.bundle.js from https://unpkg.com/jq-web@0.5.1/jq.asm.bundle.js, place it beside this file, and point the loader's first source at ./jq.asm.bundle.js.
