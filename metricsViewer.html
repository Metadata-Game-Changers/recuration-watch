Completeness by run SHARE · Prototype

Each point is one scoring run — a sample of the repository’s records as they were on that run’s date — so a rising line is re-curation you can watch happening. Thin runs (fewer than 10 records) — hollow points in Lines, dimmed cells in Grid — have noisy percentages. Switch View to a radar-plot Grid to watch each use case’s concept profile change run to run, or to Movie to animate it.
