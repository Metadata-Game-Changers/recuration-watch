The Crossref use cases — a reduced FAIR catalog

The concepts Crossref Completeness scores, use case by use case, and the exact Crossref /works field each one is drawn from. Only the concepts the Crossref schema can express are here — a reduced catalog of the Metadata Game Changers FAIR use cases.

Each Crossref work is translated to the DataCite record shape and scored with the same jq queries as Metadata Completeness, so the methodology is identical — but only the Crossref-expressible concepts are scored, and Crossref scores are not comparable to DataCite scores. This page is the quick reference; the complete concept-by-concept analysis across all fourteen use cases (which map directly, which approximately, which have no Crossref equivalent) is in the DataCite–Crossref crosswalk. Concepts marked ≈ approx are deliberate approximations — the field is the closest Crossref equivalent, not an exact match.
