Compare a set, member by member

Reads the sets.json a metrics-watch fork publishes and shows one scoring run as a grid of radar plots — rows are use cases, columns are the set’s members — so bright spots stand out at a glance. For one member’s history over time, open it in the Metrics Viewer (each column header links there).

Paste the sets.json URL from a metrics-watch fork (a GitHub link works) to compare its sets.

Set members, side by side SHARE · Prototype

One scoring run, whole set: each column is a member, each row a use case, each cell that member’s concept-profile radar with its average below. Columns sort by the group total, lowest first, so the row builds toward the bright spots — flip the Sort to lead with them instead, and click a member’s name to open its full history in the Metrics Viewer. A dimmed column means that member wasn’t scored in the selected run; its latest earlier run is shown (hover for the date).
